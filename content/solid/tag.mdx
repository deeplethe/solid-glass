## Usage

```tsx
import { Tag } from "@/components/ui/tag"
```

```tsx
<Tag icon={<PaperclipIcon />} onRemove={remove}>results.csv</Tag>
```

## States

`progress` between 0 and 1 fills the tag from the left. `error` turns it to the colour of failure and says why on hover. `armed` is the same pane lit a step brighter, for the tag the next Backspace will remove.

## Removed

A tag removed on its own x hands the keyboard on before it goes: to the next tag's x, else the one before, else the text of the composer it is in. Nothing is dropped to the page.
