## Usage

```tsx
import { StepGroup, type Step } from "@/components/ui/tool-steps"
```

```tsx
const steps: Step[] = [
  { id: "1", label: "Read search.py", status: "done" },
  { id: "2", label: "Ran pytest", status: "done", output: "12 passed" },
]

<StepGroup steps={steps} />
```

## List

`StepList` is the opened list on its own. A row opens to the call itself, or to its diff when it changed a file.

A group keeps the state of its rows. One call is one line; when a second joins it the group forms round the first, and if that call was open the group opens with it, with the keyboard still on the row it was on.

## API Reference

A `Step` is said as what it did, "Read search.py", and not as a tool's name and its arguments.

| Field | Type |
| --- | --- |
| `id` | `string` |
| `label` | `string` |
| `status` | `"running" \| "done" \| "error"` |
| `detail` | `string` |
| `output` | `string` |
| `error` | `string` |
| `patch` | `string` |
