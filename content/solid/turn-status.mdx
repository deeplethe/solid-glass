## Usage

```tsx
import { TurnStatus } from "@/components/ui/turn-status"
```

```tsx
<TurnStatus
  activity="running"
  label="Running python rerun.py"
  since={turn.startedAt}
  tokens={turn.outputTokens}
/>
```

## With steps

Given children, the line is a button and opens to show them: the calls of the step in hand. Once it has had children it stays a button, with nothing to open between steps, so the keyboard on it is not dropped as a step ends.
The activity label is announced by a separate status region, so the button keeps
its native role and updates to the clock and token count do not repeat the announcement.
When `label` is omitted or blank, the activity name supplies the announcement and
button name without adding visible text. Pass `label` to customize or translate it.

## Waiting

Until the model has sent anything there is no step to name and nothing to count, but the clock starts with the message: it is what shows the wait is being timed, not ignored. Nothing is said of the time until there is a second of it.
